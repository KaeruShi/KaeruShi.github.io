## 🎯 Overview
- Single-page portfolio with Home, About, Projects and Contact sections.
- Built with Vite + React + TypeScript and styled with Tailwind-like utilities and custom CSS.
- Project content is defined in React components (easy to edit).

## ✨ Features
- Fast dev server via Vite
- TypeScript-ready project
- Modular components: Home, About, Projects, Contact, Navbar
- Project cards driven by JS objects (easy to add new projects)
- Responsive layout and mobile-friendly navigation
